# Logic Gym 設計方向：讓小孩想一直玩（2026-11-17）

> **2026-11-18 更新**：寵物腦腦、每日任務、寶箱、花園都已拿掉，改成「我的樹＋冒險地圖」，見 `docs/tree-design.md`。本文件提到那些功能的部分已過時。

> 原則：**所有美術、動畫、音效都由程式產生**，不需要人工畫圖、不需要 Midjourney。
> 試玩版：`prototypes/puzzle-book.html`

## 1. 不寫劇情，改養寵物

舊版每關都要寫劇情，很花時間，小孩也不一定會看。改成一個「開放式的懸念」：

> 你撿到一顆會發光的蛋。每解開一題，牠就吃到一顆動腦星。蛋裡面是誰呢？

- 寵物「腦腦」完全用程式畫（SVG），會眨眼、呼吸，答對會跳，答錯會搖頭。
- **5 個成長階段**：蛋（裂開）→ 腦腦寶寶（3 星）→ 腦腦，長出星星天線（10 星）→ 探險家腦腦，戴帽子（25 星）→ 國王腦腦，戴皇冠、披披風（50 星）。
- 進度條會顯示「離下一次長大還差幾顆星」。小孩知道再解幾題就會有變化，這就是想繼續玩的動力。
- 之後可以擴充：換顏色、配件商店（用星星換）、不同品種的蛋。這些都靠程式畫，不需要美術。

## 2. 數織拼出真的圖案，收進圖鑑

- 原本數織的答案是亂數格子，現在前 20 題會拼出真正的圖案：愛心、小貓、火箭、蝴蝶……
- 圖案每張都經程式驗算過，塗法只有一種（24 張候選刷掉 3 張多解、1 張形狀寫錯，剩 20 張）。
- 拼完格子會變成圖案的顏色、一格一格閃亮，然後收進圖鑑。
- 圖鑑裡還沒收集的只顯示「?」和大小，製造好奇心，也是收集癖的來源。
- 之後新增圖案很便宜：一張圖只是一串文字（例如 `".#.#."`），寫好丟給驗算程式就好。

## 3. 「像遊戲」的手感

| 項目 | 做法 |
|------|------|
| 按鈕 | 粗邊框 + 底部陰影，按下去會「陷下去」，像實體按鍵 |
| 塗格子 | 彈一下（pop） |
| 一筆畫 | 線會像筆一樣畫出來，每多一條線音調升高一點 |
| 過關 | 彩帶噴出、過關卡片彈出、+1 ⭐ |
| 寵物長大 | 專屬的長大畫面 + 更長的音效 |
| 音效 | 用程式合成（WebAudio），不需要音檔，右上角可以關 |

所有動畫都會遵守系統的「減少動態效果」設定。

## 4. 視覺風格

- **主題**：掌上遊戲機。淡藍點點底、白色厚框遊戲板、深藍粗線。
- **顏色**：太陽黃（選中、星星）、紫（塗格子、畫線）、薄荷綠（寵物、正確）、莓果紅（錯誤、提示）。
- **字體**：數字用 Baloo 2（圓潤、像遊戲），中文用 Noto Sans TC 粗體。
- 支援深色模式。

## 5. 下一步可以加的（依效果排序）

1. **每日任務**：每天 3 題，完成拿額外星星 + 連續天數火焰。這是讓小孩每天回來的關鍵。
2. **更多謎題種類**：數字迷宮、天平推理、點燈。每多一種，「新鮮感」就多一層。
3. **寵物互動**：點腦腦會有反應、餵食動畫。
4. **家長頁**：給付費的家長看（見 `roadmap-2026-11.md`）。
