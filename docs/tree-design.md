# 我的樹：設計規格（2026-11-18）

## 為什麼改成這樣

之前做了寵物、每日任務、寶箱、衣服、花園、小動物拍照。功能太多，每一個都比不上真正的遊戲好玩。
所以只留**一個有代表性的成長感**：一棵會因為「你解開的題目」長大的樹，加上冒險地圖給方向和難度。

## 核心循環

```
冒險地圖上的一關 ──► 解開 ──► 樹喝到 1 滴水 ──► 樹當場長大一點（過關畫面看得到新長出來的東西）
                                                         │
                                                         ▼
                                              「再解 N 題就會開花」── 下一關
```

- **不用等待**：解完馬上看到變化，沒有真實時間計時、沒有懲罰。
- **每一滴水都有看得到的變化**（1～100 滴，驗證腳本會檢查）。
- BOSS 關第一次過關給 3 滴；重玩已過的關卡給 1 滴。

## 成長階段

| 水滴 | 階段 | 每滴的變化 |
|------|------|-----------|
| 0 | 一顆種子 | |
| 1 | 發芽了 | 小芽變高 |
| 3 | 小樹苗 | 每滴多一團葉子、樹變大（到 44 滴） |
| 6 | 小樹 | |
| 12 | 長高的樹 | |
| 20 | 大樹 | |
| 25 | 開花的樹 | 每滴多一朵花（16 朵） |
| 36 | 結果的樹 | 每滴多一顆果子（24 顆） |
| 50 | 有鞦韆的樹 | 鞦韆會盪 |
| 60 起 | | 每滴多一顆小燈（40 顆） |
| 70 | 有樹屋的樹 | |
| 100 | 會發光的神奇大樹 | 樹頂的星星 |

- 樹小的時候畫面會拉近，長大後慢慢拉遠。
- 天空跟著真實時間變（早上、白天、傍晚、晚上）。
- 點樹會搖一下；「成長日記」列出所有階段，還沒到的上鎖。

## 之後可以考慮

- 100 滴之後：把完成的樹移到「森林」，再種一棵不同種類的樹（櫻花、楓樹、椰子樹⋯⋯）。

## 難度曲線（2026-11-18）

三種謎題在冒險地圖上輪流出現，每一種的第 L 題：

| 謎題 | 怎麼變難 |
|------|---------|
| 數織 | 20 張圖案題自動照難度排（5×5 → 6×6 → 7×7，同大小再比要推幾輪）；做完後是 7×7 挑戰題 |
| 一筆畫 | 從 6 條線開始，每兩題多 1 條，最多 16 條；格點 3×3 → 4×3 → 4×4 |
| 數獨 | 從 11 格提示（只空 5 格）開始，每兩題少 1 格，最少 5 格 |

- BOSS 只比平常難一點（約等於往後兩題）。
- 所有數織都必須「一排一排推得出來、不用猜」，驗證腳本會檢查（原本的笑臉、烏龜要用猜的，已重畫）。
- 說明平常收起來：第一次玩某種謎題會自動跳出示範，之後只剩一行「❓ 忘記怎麼玩？點這裡」。
